# 🏀 Double Clutch

기획 파트와 협업하여 제작한  
**캐주얼 농구 육성 시뮬레이션 게임**입니다.

플레이어는 팀을 운영하며  
주차 단위로 진행되는 시즌 속에서 선수 육성, 경기 진행, 이벤트 선택을 통해  
팀을 성장시키고 리그 우승을 목표로 합니다.

---

## 🎮 게임 플레이

- 주차 단위 시즌 진행
- 선수 육성
- 경기 진행
- 이벤트 선택
- 리그 순위 경쟁
- 시즌 종료 및 결과 확인

# 주요 구현 기능

## 1️⃣ 주차 기반 캘린더 시스템

게임 진행을 주차 단위로 관리하는  
캘린더 시스템을 구현했습니다.

### 역할
- 일정 진행 관리
- 경기 일정 처리
- 이벤트 발생 시점 관리
- 시즌 흐름 제어

### 개선 내용
하드코딩된 날짜 처리 대신  
데이터 기반으로 일정이 확장 가능하도록 설계했습니다.

---

## 2️⃣ 이벤트 기반 게임 흐름 관리

게임 내 다양한 이벤트를  
중앙에서 관리하는 구조를 설계했습니다.

### 이벤트 예시
- 훈련 이벤트
- 스폰서 이벤트
- 선수 성장 이벤트
- 경기 결과 이벤트

### 개선 내용
각 기능이 직접 참조하지 않도록  
이벤트 기반 구조로 결합도를 낮췄습니다.

---

## 3️⃣ 전략 패턴 기반 리그 타이브레이커 시스템

동률 발생 시 다양한 순위 계산 조건을  
유연하게 처리하기 위해 전략 패턴을 적용했습니다.

### 처리 조건
- 승률 비교
- 득실 차 비교
- 추가 우선순위 계산

새로운 조건 추가 시  
기존 코드를 수정하지 않도록 설계했습니다.

---

## 4️⃣ UI 모듈화 및 DI 적용

UI 기능을 모듈 단위로 분리하고  
DI를 적용해 의존성을 낮췄습니다.

### 개선 내용
- UI 재사용성 향상
- 테스트 용이성 개선
- 유지보수 비용 감소

---

# 🧩 기술적 고민

육성 게임 특성상  
새로운 이벤트와 콘텐츠가 지속적으로 추가될 가능성이 높았습니다.

초기 구조에서는 기능 간 직접 참조가 많아  
확장 시 유지보수 비용이 증가할 가능성이 있었습니다.

이를 해결하기 위해

- 이벤트 기반 구조 설계
- 전략 패턴 적용
- UI 모듈화
- DI 적용

을 통해 확장 가능한 구조를 만드는 데 집중했습니다.
